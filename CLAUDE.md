# Coffee Manager — правила для Claude

Telegram-бот учёта для кофейни (python-telegram-bot, SQLite). Пилот: кофейня в Тольятти, рубли, время Самары (UTC+4).

## Файлы
- bot.py — вся логика бота
- config.py — настройки из .env (токен, ADMIN_IDS, валюта, часовой пояс)
- database.py — схема SQLite и бэкапы
- setup_shop.py + shop_data.example.json — заливка меню/склада/рецептов кофейни
- Не в Git: .env, *.db, backups/, shop_data.json, *.log

## Запуск
source .venv/bin/activate && python3 bot.py

## Как работаем
- В начале сессии прочитай STATUS.md, сверь с `git log` и кодом. Если расходятся — верь коду и скажи об этом.
- Одно действие → результат → следующее. Не переписывай то, что работает.
- Не добавляй функции без запроса пилота (мультиаккаунт, веб-панель, AI-анализ — нет).
- В конце сессии обнови STATUS.md, закоммить, отчёт в формате DONE / ISSUES / NEXT (+ BUSINESS RISK, если есть).
- Секреты никогда не коммить и не выводи в терминал.
